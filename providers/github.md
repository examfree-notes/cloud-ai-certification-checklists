## Official Domain Checklists (Active & Retiring Exams)

### `GITHUB-COPILOT` — GitHub Certified Copilot

**Level:** Intermediate · **Duration:** 100 minutes · **Passing Score:** 700 (scale 1–1,000) · **Practice Questions:** [57 questions (18 free preview)](https://examfree.org/exam/github-copilot) · [Sample Q1](https://examfree.org/exam/github-copilot/question-1)

- [ ] **Use GitHub Copilot responsibly** (`15–20%`)
- [ ] **Use GitHub Copilot features** (`25–30%`)
- [ ] **Understand GitHub Copilot data and architecture** (`10–15%`)
- [ ] **Apply prompt engineering and context crafting** (`10–15%`)
- [ ] **Improve developer productivity with GitHub Copilot** (`10–15%`)
- [ ] **Configure privacy, content exclusions, and safeguards** (`10–15%`)

*Format note:* Microsoft doesn't publish an exact question count for each exam. It states that most Microsoft Certification exams typically contain between 40 and 60 questions, and that the number can vary depending on the exam.
